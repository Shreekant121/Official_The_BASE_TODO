Binary toggle. Off is a recessed well; on is emerald glass that emits.

```jsx
<Switch label="Strict mode" defaultChecked />
<Switch checked={sync} onChange={setSync} size="sm" />
```

- Use for settings that apply immediately. For anything needing a Save, use `Checkbox`.
- The on-state glows because it is *active* — this is the one control where glow is always correct.
- Label goes after the control, never before.
